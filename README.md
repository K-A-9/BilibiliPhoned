# BilibiliPhoned
Mobile interface adaptation for Bilibili's desktop web version.
> 让 B 站电脑版网页在手机上拥有类似原生 App 的浏览体验

一个 Tampermonkey / Violentmonkey 用户脚本。以 **CSS 为主、JS 为辅**，把 B 站电脑版网页改造成手机端适配布局，隐藏冗余的 PC 组件，重排播放器、评论、动态、空间等页面。

---

## ✨ 特性一览

### 通用适配
- 隐藏 PC 顶部导航、侧栏、页脚、悬浮工具条等冗余组件
- 内置 **52px 顶部搜索栏**，支持综合 / 直播 / 专栏 / 用户类型切换
- 首页、搜索页、空间页等全站卡片 **两列网格布局**
- 禁止全站横向溢出，杜绝页面左右抖动
- 鼠标滚轮在任意位置都可纵向滚动页面（排除底栏与搜索栏）
- 底部仿手机 App 导航栏：**首页 / 动态 / 热门 / 刷新 / 我的**

### 搜索页
- 支持 `-关键词` 排除语法（例：`洛克王国 -手游`）
- 支持 `+关键词` 强制包含
- 搜索页顶部显示已屏蔽词与过滤数量，可一键清除
- 排序（综合 / 最新）与搜索类型（综合 / 直播 / 专栏 / 用户）快捷切换

### 视频 · 播放列表 · 番剧页
- 播放器 **16:9 满宽**，蓝色描边视觉风格
- 控制栏手机化：隐藏画中画 / 宽屏 / 播放列表按钮
- 从屏幕右侧向左滑即可呼出右侧推荐列表（带遮罩）
- 鼠标拖拽也支持呼出 / 收起侧栏
- 视频标题、简介、评论区居中排版
- 工具栏改造为 **点赞 / 投币 / 收藏 / 分享** 四按钮（调用 B 站原站逻辑，可正常生效）
- **UP 主单行卡片**：头像 + 名字 + 关注按钮，不再多行溢出
- 鼠标伸入播放器 → 展开进度条；静止 3 秒 → 自动收起；再次移动 → 重新展开（鼠标仍可见）
- **禁用 B 站原生小窗浮动播放器**
- 视频窗口不可拖动，位置与尺寸固定
- 原生全屏与网页全屏均正常适配

### 网页全屏
- 自动铺满整个视口
- 自动隐藏底栏、搜索栏、动态顶栏
- **自动隐藏所有弹幕功能**（弹幕发送栏、弹幕设置、弹幕开关）
- 倍速 / 音量 / 网页全屏 / 屏幕全屏按钮固定在右下角可见位置

### 动态 · 话题 · Opus
- 卡片两列布局，图片、视频等比缩放
- 评论区左右对齐
- **顶部 UP 头像条**：横向可滚动的"有更新的 UP"列表，点击直接进入对应空间

### UP 主空间
- 投稿、合集、动态等列表两列布局
- 顶部信息卡固定在屏内，不再溢出

### 直播间
- 只保留播放器与聊天区
- 双击播放器进出原生全屏
- 返回键优先退出全屏
- 控制栏仅保留时间与清晰度
- 遮罩铺满整个播放器

### "我的"面板
- 点击底栏"我的"弹出底部上滑面板
- 快捷入口：**我赞过 / 收藏 / 历史 / 稍后再看 / 设置**
- 自动从 Cookie 读取 UID 拼接个人空间链接

### 宽布局页
- 动态页、收藏、我赞过、历史、稍后再看、设置、热门等原 PC 宽布局页面
- 保留原始页面宽度（1240px 起），浏览器自动出现**横向滚动条**
- 自定义 10px 滚动条样式，视觉更清爽

## 📦 安装

### 前置条件
- 浏览器：Chrome / Edge / Firefox / Safari / 任意支持用户脚本的浏览器
- 用户脚本管理器：推荐 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)

### 安装步骤
1. 安装 Tampermonkey 或 Violentmonkey 扩展
2. 新建一个用户脚本
3. 把本仓库中的脚本内容整体粘贴进去
4. 保存后刷新任意 B 站页面即可生效

## 🛠️ 实现方式

### 设计原则
- **CSS 优先**：能用 CSS 解决的绝不写 JS，减少性能开销与不可预期的副作用
- **JS 补位**：只处理 CSS 无法完成的事情，例如：
  - 页面 class 动态同步（SPA 路由变化）
  - Shadow DOM 内部样式注入
  - 播放器控制栏重排
  - 鼠标 / 触摸手势
  - 底栏与"我的"面板的 DOM 创建

### 关键技术点
- `body.bili-xxx-page` 页面标记 class，由 JS 在路由变化时同步
- `:has()` 选择器精确匹配播放器状态（如 `data-screen="web"`）
- `MutationObserver` 监控动态内容加载与视频页状态变化
- 屏蔽 B 站的原生小窗：持续监听 `.bpx-player-container` 的 `class` 与 `data-screen` 属性

## ⚠️ 已知限制

- B 站网页结构更新可能导致部分选择器失效，脚本会在页面加载后多次重试以保证适配
- 网页全屏时弹幕功能被完整隐藏（这是**有意设计**，避免占用视口空间）
- 宽布局页在小屏下需要横向滚动浏览，属于**刻意保留的 PC 体验**(可能会出现横向滚动条加载不出来的情况)
- 正常模仿手机刷视频还可以, 若要看直播或特殊页面, 请移至电脑网页端或手机APP端

## 🔧 自定义

脚本内所有关键 CSS 变量都集中在 `injectStyle()` 函数里，便于修改：

- **主题色**：搜索 `#00aeec` 全局替换
- **播放器边框**：搜索 `#playerWrap`，`border: 3px solid #00aeec`
- **底部导航栏高度**：搜索 `#my-bili-bottom-nav`，`height: 52px`
- **搜索栏高度**：搜索 `#my-bili-searchbar`，`height: 52px`
- **宽布局页最小宽度**：搜索 `min-width: 1240px`
